# Health-Clinic Queue Manager
**COS 202 - Assignment 4 (MAAUN)**
**Lecturer: Engr. Hassan Yau Hamisu**

## Project Overview
This is a functional Health-Clinic Queue Manager built using Flask. It allows for patient registration and manages a waiting list using a First-In, First-Out (FIFO) Queue structure.

## Features & Requirements Met
- **OOP:** Data is encapsulated within a custom `Patient` Class rather than raw dictionaries.
- **Data Structures:** Successfully implemented a FIFO Queue to manage patient order.
- **APIs:** Utilized the `datetime` module for precise arrival timestamping.
- **Flask UI:** Features working routes for the Home page and patient registration.

## How to Run Locally
1. Ensure Python and Flask are installed: `pip install Flask`.
2. Navigate to the project directory: `cd clinic_app`.
3. Start the application: `python app.py`.
4. Access the web interface: Open `http://127.0.0.1:5000` in any web browser.
